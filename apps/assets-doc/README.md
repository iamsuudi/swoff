# @swoff/assets-doc

Marketing page for [@swoff/assets](https://github.com/iamsuudi/swoff) — deploy target `assets.swoff.space`.

Single-page static site: hero, interactive command builder, features, generated-files table, comparison, and CTA. Built with React, Vite, Tailwind CSS v4, base-ui primitives, and the Swoff-generated PWA assets (in `public/`).

## Stack

- [Vite](https://vitejs.dev/) + React 19 (pure SPA, no framework)
- [Tailwind CSS](https://tailwindcss.com/) v4 with the fumadocs "black" color palette (vendored into `src/styles/app.css`)
- [base-ui](https://base-ui.com/) shadcn-style components in `src/components/ui/`
- [Biome](https://biomejs.dev/) for lint/format

## Scripts

```bash
bun run dev          # dev server (localhost:3000)
bun run build        # static build to dist/
bun run preview      # preview the production build
bun run lint         # biome check
bun run check-types  # tsc --noEmit
```

## Deploy

Netlify (`netlify.toml`): publish `dist`, SPA fallback to `/index.html`, immutable cache headers for generated icons.

Public assets (favicons, OG image, manifest, splash screens, `pwa-debug.html`) are generated by `@swoff/assets` and checked in.
