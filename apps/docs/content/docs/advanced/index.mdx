## Advanced Patterns

These patterns solve real-world production needs — conflict resolution, authentication, push notifications, and more. Each is optional and independent.

| Pattern | What it solves |
|---|---|
| [Mutation Queuing](/docs/advanced/mutation-queuing) | Queue offline writes and sync when online |
| [Background Sync](/docs/advanced/background-sync) | Process queue after tab close (Chrome/Edge) |
| [Push Notifications](/docs/advanced/push-notifications) | Re-engage users with push notifications |
| [Testing](/docs/advanced/testing) | Test service workers, IndexedDB, and offline behavior |
| [Debugging](/docs/advanced/debugging) | Debug SW, cache, IndexedDB with DevTools |
| [Conflict Resolution](/docs/advanced/conflict-resolution) | Handle concurrent offline edits |
| [Authentication](/docs/advanced/authentication) | Auth-aware offline architecture |
