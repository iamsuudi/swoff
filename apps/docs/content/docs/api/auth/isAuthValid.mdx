## `isAuthValid(auth)`

From `swoff/auth/store.ts`. Returns `true` if auth exists and `expiresAt` (if set) is in the future.

```ts
import { isAuthValid } from "swoff/auth/store";

if (isAuthValid(auth)) { /* valid */ }
```
