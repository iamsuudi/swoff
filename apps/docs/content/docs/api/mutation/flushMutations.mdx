## `flushMutations(options?)`

From `swoff/mutation/queue.ts`. Flush (`flushMutations`) reads and processes all pending mutations, returning per-item `{ id, status, response?, error? }`.

```ts
import { flushMutations } from "swoff/mutation/queue";
```
