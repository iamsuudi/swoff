## `getMutationState(id)`

From `swoff/mutation/state.ts`.

```ts
import { getMutationState } from "swoff/mutation/state";
```

Returns `{ status: 'pending' | 'in-flight' | 'completed' | 'failed', error?, rollbackData? }` or `undefined`.
