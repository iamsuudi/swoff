## CLI (Future)

> **Note**: Currently, copy code snippets manually from docs.

## Vision

A CLI tool to:

1. **Download code** — Fetch components, hooks, utilities
2. **Configure project** — Setup file structure
3. **Zero deps** — Code lives in your project

## Planned Commands

```bash
npx swoff init              # Initialize project
npx swoff add update-prompt  # Download component
npx swoff add usePWAUpdate  # Download hook
npx swoff list              # List available
```
