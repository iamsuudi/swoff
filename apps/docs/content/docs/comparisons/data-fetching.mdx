# Data Fetching: Swoff vs TanStack Query / SWR

The difference between data-fetching approaches lies in the _storage layer_ and _thread_ where caching happens. Swoff's caching strategies and 3-tier resolution system are covered in [Caching & Data Layer](/docs/comparisons/caching-and-data). This doc focuses on the developer-facing API and practical implications of SW-level vs in-memory caching.

## How Swoff does it

`useCachedFetch` is a thin React hook over `fetchWithCache`, which communicates with the Service Worker via the `fetch` event. The SW intercepts every request, applies the configured strategy, and stores responses in the Cache Storage API.

```
useCachedFetch("/api/notes")
  → fetchWithCache("/api/notes")
    → SW fetch event handler
      → applies strategy
      → caches or serves from Cache Storage API
      → returns Response to client
  → useCachedFetch sets data/error/loading state
```

**Key properties:**

- **Storage layer:** Cache Storage API (disk-backed, persists across tab closes and hard navigations).
- **Thread:** Service Worker thread. Cache lookup, strategy logic, and background refresh don't block the main thread.
- **Offline:** Native. Cached responses served from the Cache Storage API regardless of connectivity.
- **Hard navigation:** Survives page reload.
- **Bundle impact:** 0 kB. The hook is generated source code.
- **Framework coupling:** None. Works with any framework.

## How TanStack Query / SWR handles it

TanStack Query and SWR are in-memory server-state caching libraries. They run on the main thread, store data in a JavaScript `Map`/`QueryCache`, and provide hooks for fetching, caching, revalidating, and deduplicating requests.

**Key properties:**

- **Storage layer:** In-memory. Data is lost on tab close, page refresh, or memory pressure.
- **Thread:** Main thread. All cache reads, writes, and revalidation compete with rendering.
- **Strategies:** One strategy — stale-while-revalidate (with configurable `staleTime` and `gcTime`).
- **Offline:** Not natively offline. Requires a `persister` adapter.
- **Hard navigation:** Does not survive page reload.
- **Bundle impact:** ~3.8 kB gzip (TanStack Query) or ~3.3 kB gzip (SWR).
