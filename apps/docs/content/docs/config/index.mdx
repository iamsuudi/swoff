# Configuration Reference

Full schema for `swoff.config.json` — every field, its type, default, and description.

## The caching umbrella

In schema v2, every cache-related feature lives under a single `features.caching` object. Swoff is **offline-first by default**: when `features.caching.enabled` is `false`, the generated service worker has **no fetch listener** — it never intercepts network requests. Turn on the umbrella, then opt into the sub-features you need:

- `features.caching.strategy`, `features.caching.navigation`, `features.caching.precache` — the request/asset engine
- `features.caching.requestBatchWindowMs`, `features.caching.refetchQueue` — request coalescing and background refresh
- `features.caching.mutationQueue`, `features.caching.tagInvalidation`, `features.caching.serverPush`, `features.caching.graphql` — the offline mutation and invalidation stack

**Rules.** Any effective sub-feature of `caching` requires `features.caching.enabled` to be `true`. `serverPush.enabled` additionally requires `tagInvalidation.enabled`. `mutationQueue.backgroundSync` requires `mutationQueue.enabled`. `caching.serverPush` is not supported with `auth.type: "bearer"` (or `"custom"`).

```json
{
  "features": {
    "connectivity": { "enabled": false },
    "caching": {
      "enabled": true,
      "mutationQueue": { "enabled": true },
      "tagInvalidation": { "enabled": true }
    }
  }
}
```

> **Schema v1 → v2:** migrated from `features.tagInvalidation`, `features.mutationQueue`, `features.graphql`, `features.serverPush`, `features.requestBatchWindowMs`, `features.refetchQueue`, and `features.serviceWorker.{strategy,navigation,precache}`. See the [migration guide](/docs/config/migration-v2).

> **Connectivity is off by default.** `features.connectivity.enabled` defaults to `false`; enable it explicitly for online/offline monitoring. With `auth.enabled`, the shared `online-status` module is generated automatically so `auth/state` works without the connectivity feature.

## Quick reference

```json
{
  "$schema": "https://swoff.space/schema/v2.json",
  "framework": "react",
  "build": {
    "swOutput": "dist",
    "swoffPath": ".",
    "swUrl": "/swoff.sw.js"
  },
  "features": {
    "connectivity": {
      "enabled": false,
      "heartbeatIntervalMs": 30000
    },
    "pushNotifications": false,
    "pwa": {
      "enabled": false,
      "preventDefaultInstall": false
    },
    "auth": {
      "enabled": false,
      "type": "cookie",
      "routePaths": [
        "/api/login",
        "/api/logout",
        "/api/register",
        "/api/refresh",
        "/api/me"
      ]
    },
    "serviceWorker": {
      "autoActivate": false
    },
    "caching": {
      "enabled": false,
      "strategy": {
        "default": "cache-first",
        "patterns": {
          "/api/*": {
            "strategy": "reactive",
            "staleTime": 30,
            "refetchOnFocus": true
          },
          "/static/*": "cache-first"
        },
        "reactive": {
          "staleTime": 0,
          "refetchInterval": 0,
          "refetchOnReconnect": false,
          "refetchOnFocus": false
        },
        "maxRuntimeCacheAge": 2592000,
        "normalizeKey": false,
        "ignoreQueryParams": [],
        "timeout": 10,
        "storageThreshold": 80
      },
      "navigation": {
        "mode": "spa",
        "preload": true,
        "fallback": "/index.html",
        "precacheRoutes": [],
        "rules": []
      },
      "precache": { "concurrency": 1 },
      "requestBatchWindowMs": 50,
      "refetchQueue": {
        "batchSize": 5,
        "batchDelayMs": 1000,
        "retry": {
          "maxRetries": 3,
          "backoffMs": 1000,
          "maxBackoffMs": 10000,
          "jitterMs": 100
        }
      },
      "mutationQueue": {
        "enabled": false,
        "batchSize": 1,
        "batchDelayMs": 0,
        "retry": {
          "maxRetries": 5,
          "backoffMs": 1000,
          "maxBackoffMs": 30000,
          "jitterMs": 250
        },
        "backgroundSync": false
      },
      "tagInvalidation": {
        "enabled": false,
        "debounceMs": 0,
        "skipPrefixes": ["api", "v1", "v2", "v3", "rest", "graphql", "gql"],
        "patterns": {},
        "singularization": {},
        "cascading": {}
      },
      "graphql": {
        "enabled": false,
        "endpoints": ["/graphql"]
      },
      "serverPush": {
        "enabled": false,
        "type": "sse",
        "endpoint": "/api/events",
        "reconnectDelayMs": 5000
      }
    }
  }
}
```

> **The example above shows the complete schema.** `swoff init` generated configs are fully explicit: every field of each **enabled** feature is materialized (booleans included), while disabled optional features are omitted entirely. `strategy.reactive` is only emitted when `strategy.default` is `"reactive"`, and `build.swoffPath` is emitted as `"."` — which, like an empty value, resolves to the default `"swoff"` directory.
