## `features.caching.requestBatchWindowMs`

| Field                  | Type     | Default | Description                                                                                                              |
| ---------------------- | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `requestBatchWindowMs` | `number` | `50`    | Time window in ms to coalesce concurrent GET requests to the same URL before dispatching to the SW. 0 disables batching. |

<Callout type="info" title="Schema v2">
Previously `features.requestBatchWindowMs`. Only effective when `features.caching.enabled` is `true`. See the [migration guide](/docs/config/migration-v2).
