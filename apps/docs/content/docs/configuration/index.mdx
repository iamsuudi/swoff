# Getting Started with Configuration

Swoff uses a JSON config. Run the CLI to generate the SW and supporting files.

## Quick Setup

```bash
# Initialize (creates swoff.config.json + directory structure)
npx @swoff/cli init

# Review and customize the config
nano swoff.config.json

# Generate service worker + supporting files
npx @swoff/cli generate
```

The CLI creates:

| Config | Creates |
|--------|---------|
| `swoff.config.json` | Service worker + version.json |
| `src/hooks/` | `useOffline.ts`, `useApiData.ts` |
| `src/components/` | `OfflineIndicator.tsx`, `PWAInstallButton.tsx` |
| `src/utils/` | `crossTabSync.ts` |

Generated based on `features` toggles in your config.

## Configuration

```json
{
  "$schema": "https://swoff.netlify.app/schema/v1.json",
  "enabled": true,
  "version": "from-package",
  "minSupportedVersion": "1.0.0",
  "serviceWorker": {
    "autoActivate": false,
    "defaultStrategy": "cache-first",
    "strategies": {
      "/api/*": "network-first",
      "/static/*": "cache-first"
    }
  },
  "features": {
    "versionedSw": true,
    "offlineReads": true,
    "mutationQueue": false,
    "backgroundSync": false,
    "pwa": true,
    "auth": false,
    "crossTabSync": true,
    "tagInvalidation": true
  },
  "build": {
    "outputDir": "dist",
    "swFilename": "sw"
  }
}
```
