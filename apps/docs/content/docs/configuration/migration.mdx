# Migration Guide

Gradually move from manual SW code to config-driven generation.

## 1. Create Config

```bash
npx @swoff/cli init
```

This creates `swoff.config.json`. Or create it manually:

```json
{
  "$schema": "https://swoff.netlify.app/schema/v1.json",
  "enabled": true,
  "version": "from-package",
  "serviceWorker": {
    "autoUpdate": false,
    "defaultStrategy": "cache-first"
  },
  "features": {
    "versionedSw": true,
    "offlineReads": true
  }
}
```

## 2. Generate SW

```bash
npx swoff generate
```

Creates `dist/sw-v{version}.js` and `dist/version.json`.

## 3. Register

Replace your manual SW registration with:

```javascript
if ('serviceWorker' in navigator) {
  fetch('/version.json')
    .then(r => r.json())
    .then(({ version }) => {
      navigator.serviceWorker.register(`/sw-v${version}.js`);
    });
}
```

## 4. Add Features Incrementally

```json
{
  "features": {
    "offlineReads": true,
    "mutationQueue": true,
    "crossTabSync": true
  }
}
```

Run `npx swoff generate` after each change.

## 5. Custom Cache Strategies

```json
{
  "serviceWorker": {
    "strategies": {
      "/api/*": "network-first",
      "/static/*": "cache-first",
      "/images/*": "stale-while-revalidate"
    }
  }
}
```

## 6. Disable Config (Custom Code Mode)

If you need full custom SW code:

```json
{
  "enabled": false
}
```

Then write your own `sw.js` manually.

## Manual → Config Mapping

| Manual | Config |
|--------|--------|
| `CACHE_NAME = 'my-app-v1.0.0'` | `version: "from-package"` |
| `caches.match()` | Handled by generator |
| `caches.put()` | Handled by generator |
| Manual version cleanup | `versionedSw: true` |

## Rollback

Set `"enabled": false` in config and restore your manual SW file.
