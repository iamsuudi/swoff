# Configuration Schema

Full schema at `https://swoff.netlify.app/schema/v1.json`.

## Fields

### Root

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `enabled` | boolean | `true` | Enable config-driven generation |
| `version` | string | `"from-package"` | SW version. Use `"from-package"` to read from package.json, or specify semver like `"1.0.0"` |
| `minSupportedVersion` | string | `"0.0.0"` | Force update for clients running older versions |

### serviceWorker

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `autoRegister` | boolean | `true` | Automatically register SW on page load. Set `false` for deferred registration (e.g., after onboarding) |
| `autoUpdate` | boolean | `false` | `true` = silent update (skipWaiting), `false` = dispatch `sw-update-available` event for user consent |
| `defaultStrategy` | string | `"cache-first"` | Default caching strategy |
| `strategies` | object | `{}` | Per-URL pattern strategies |
| `maxCacheEntries` | integer | `100` | Max cached entries |
| `maxCacheAge` | integer | `604800000` | Max cache age in ms (7 days) |
| `runtimeCacheName` | string | `"swoff-runtime"` | Runtime cache name |

### strategies values

- `cache-first` — Serve cache, fall back to network
- `network-first` — Try network, fall back to cache
- `stale-while-revalidate` — Serve cached, refresh in background
- `cache-only` — Cache only
- `network-only` — Network only

### features

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `versionedSw` | boolean | `true` | Versioned SW (prevents silent updates) |
| `offlineReads` | boolean | `true` | Cache API responses for offline reads |
| `mutationQueue` | boolean | `false` | Queue offline writes, sync on reconnect |
| `backgroundSync` | boolean | `false` | Background Sync API (Chrome/Edge only) |
| `pwa` | boolean | `true` | PWA installability |
| `auth` | boolean | `false` | Auth integration |
| `crossTabSync` | boolean | `true` | Cross-tab cache invalidation |
| `tagInvalidation` | boolean | `true` | Tag-based cache invalidation |
| `clientRegistration` | boolean | `true` | Generate client-side SW registration code (`sw-injector`) |
| `indexeddb` | boolean | `false` | Generate IndexedDB storage patterns |

### pwa

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `preventDefaultInstall` | boolean | `false` | When `false`, browser shows native install prompt naturally while event is captured. When `true`, prompt is suppressed and dev must call `promptInstall()` manually |

### build

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `outputDir` | string | `"dist"` | Output directory |
| `swFilename` | string | `"sw"` | SW filename (without version) |

### database

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `name` | string | `"app-db"` | IndexedDB name |
| `stores` | array | `[]` | Object store names |

## Example Config

```json
{
  "$schema": "https://swoff.netlify.app/schema/v1.json",
  "enabled": true,
  "version": "from-package",
  "minSupportedVersion": "1.0.0",
  "serviceWorker": {
    "autoRegister": true,
    "autoUpdate": false,
    "defaultStrategy": "cache-first",
    "strategies": {
      "/api/*": "network-first",
      "/static/*": "cache-first"
    }
  },
  "features": {
    "versionedSw": true,
    "offlineReads": true,
    "mutationQueue": false,
    "backgroundSync": false,
    "pwa": true,
    "auth": false,
    "crossTabSync": true,
    "tagInvalidation": true,
    "clientRegistration": true,
    "indexeddb": false
  },
  "pwa": {
    "preventDefaultInstall": false
  },
  "build": {
    "outputDir": "dist",
    "swFilename": "sw"
  }
}
```

## Validation

```bash
npx ajv validate -s https://swoff.netlify.app/schema/v1.json -d swoff.config.json
```

Or use the CLI:

```bash
npx @swoff/cli validate
```
