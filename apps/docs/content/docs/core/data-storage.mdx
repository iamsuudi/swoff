# Data Storage Strategy

Offline-first apps need client-side storage. Choose the right API for the job.

## Storage Options

| API | Capacity | Data Type | Sync | Use Case |
|-----|----------|-----------|------|----------|
| **IndexedDB** | ~50MB+ | Structured | Async | App data (todos, users, etc.) |
| **localStorage** | ~5MB | Strings | Sync | Settings, metadata |
| **sessionStorage** | ~5MB | Strings | Sync | Session state (cleared on close) |
| **Cache API** | Unlimited* | Requests | Async | SW asset caching |

*Limited by disk space and browser quota

## IndexedDB (Primary Data Store)

Use IndexedDB for **structured application data**:

- Todos, notes, expenses, users, etc.
- Large datasets
- Complex queries with indexes
- Need for migrations

### Native IndexedDB (Zero Dependency)

```javascript
// Open database
function openDB() {
  return new Promise((resolve, reject) => {
    const request = indexedDB.open('my-app', 1)

    request.onupgradeneeded = (e) => {
      const db = e.target.result
      const store = db.createObjectStore('todos', { keyPath: 'id' })
      store.createIndex('by-date', 'date')
    }

    request.onsuccess = (e) => resolve(e.target.result)
    request.onerror = (e) => reject(e.target.error)
  })
}

// Add item
async function addTodo(todo) {
  const db = await openDB()
  const tx = db.transaction('todos', 'readwrite')
  const store = tx.objectStore('todos')
  store.add(todo)
  await tx.done // If using idb wrapper, else: await new Promise(r => tx.oncomplete = r)
}

// Get all
async function getAllTodos() {
  const db = await openDB()
  const tx = db.transaction('todos', 'readonly')
  const store = tx.objectStore('todos')
  return new Promise((resolve, reject) => {
    const request = store.getAll()
    request.onsuccess = () => resolve(request.result)
    request.onerror = () => reject(request.error)
  })
}
```

### With idb Library (Optional)

If you prefer promises over event handlers:

```javascript
import { openDB } from 'idb' // npm install idb

const db = await openDB('my-app', 1, {
  upgrade(db) {
    db.createObjectStore('todos', { keyPath: 'id' })
  }
})

await db.add('todos', { id: 1, text: 'Hello' })
const todos = await db.getAll('todos')
```

**Choice**: Swoff provides both patterns. Use native for zero deps, or `idb` for cleaner code.

## localStorage (Metadata)

Use localStorage for **small, simple values**:

```javascript
// Settings
localStorage.setItem('theme', 'dark')
const theme = localStorage.getItem('theme')

// Flags
localStorage.setItem('welcome-seen', 'true')
const seen = localStorage.getItem('welcome-seen') === 'true'

// Version tracking
localStorage.setItem('swRegisteredVersion', '1.0.0')
```

**Limitations**:
- Synchronous (blocks main thread)
- Strings only (must JSON.stringify objects)
- ~5MB limit
- No indexes or queries

## sessionStorage (Session State)

Use sessionStorage for **temporary state**:

```javascript
// Cleared when tab closes
sessionStorage.setItem('current-view', 'list')
const view = sessionStorage.getItem('current-view')
```

## Cache API (SW Assets)

Used by Service Worker for asset caching (not app data):

```javascript
// In SW
const cache = await caches.open('my-app-v1')
await cache.add('/index.html')

// Retrieve
const response = await cache.match('/index.html')
```

## Storage Quota

Check available storage:

```javascript
const estimate = await navigator.storage.estimate()
console.log(`Using ${estimate.usage} of ${estimate.quota} bytes`)
```

## Swoff's Recommendation

```
┌─────────────────────────────────────┐
│         App Data Strategy           │
│                                     │
│  IndexedDB                          │
│  - Todos, notes, expenses           │
│  - User data, settings with structure│
│  - Large datasets                   │
│                                     │
│  localStorage                       │
│  - UI preferences (theme, language) │
│  - Feature flags                    │
│  - SW version tracking              │
│                                     │
│  sessionStorage                     │
│  - Current route state              │
│  - Form draft data                  │
│  - Temporary flags                  │
│                                     │
│  Cache API (via SW)                 │
│  - Static assets (HTML, JS, CSS)    │
│  - Images, fonts                    │
└─────────────────────────────────────┘
```
