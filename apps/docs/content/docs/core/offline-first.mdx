# Offline Architecture

Build web apps that work **fully offline** — no server required after first load.

## Principles

1. **Client-Only Runtime** — All logic runs in browser
2. **Offline-First Storage** — IndexedDB for data, localStorage for config
3. **Service Worker Caching** — All static assets cached

## Architecture

```
┌────────────────────────┐
│     Browser Tab         │
│  ┌──────────────────┐ │
│  │  React/Vue App   │ │
│  │  IndexedDB data  │ │
│  └──────────────────┘ │
│  ┌──────────────────┐ │
│  │ Service Worker    │ │
│  │ (cache storage)   │ │
│  └──────────────────┘ │
└────────────────────────┘
```

## Storage Strategy

### IndexedDB (Primary)

For structured data (todos, notes, etc.):

```typescript
import { openDB } from 'idb'

const db = await openDB('my-app', 1, {
  upgrade(db) {
    db.createObjectStore('items', { keyPath: 'id' })
  },
})
```

### localStorage (Metadata)

For small config values:

```typescript
localStorage.setItem('app-version', '1.0.0')
```

### sessionStorage (Session State)

For temporary state (cleared on tab close):

```typescript
sessionStorage.setItem('auth', 'true')
```

## Data Flow

**Online (First Visit):**
1. Browser loads `index.html`
2. SW registers and caches assets
3. App initializes, data saved to IndexedDB

**Offline (Subsequent):**
1. SW serves from cache (instant)
2. App loads from cache
3. IndexedDB data available
4. Full functionality!

## Session Management

Survive refreshes, clear on tab close:

```typescript
// On login
sessionStorage.setItem('auth', 'true')

// On page load
if (sessionStorage.getItem('auth') === 'true') {
  showApp()
} else {
  showLogin()
}
```

## Soft Deletes

Instead of permanent deletion:

```typescript
// Mark as deleted
await db.put('items', { ...item, deletedAt: Date.now() })

// Query active only
const items = await db.getAll('items')
const active = items.filter(i => !i.deletedAt)
```

## Offline Checklist

- [ ] SW caches all static assets
- [ ] IndexedDB initialized on first load
- [ ] App works without network after first visit
- [ ] Data persists across sessions
- [ ] Tested in airplane mode!
