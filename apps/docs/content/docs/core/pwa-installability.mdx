## Prerequisites

1. **HTTPS or localhost** — Required for SW and PWA
2. **Service Worker** — Already set up
3. **Web App Manifest** — Describes your app

## Create Manifest [step]

Create `public/manifest.json`:

```json
{
  "name": "My Offline App",
  "short_name": "MyApp",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#000000",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" }
  ]
}
```

## Link in HTML [step]

Update `index.html`:

```html
<link rel="manifest" href="/manifest.json" />
<meta name="theme-color" content="#000000" />
```

## Handle Install Prompt [step]

```typescript
// Capture install prompt
window.addEventListener("beforeinstallprompt", (e) => {
  e.preventDefault();
  window.deferredInstallPrompt = e as any;
});

// Trigger install
async function promptInstall() {
  await window.deferredInstallPrompt?.prompt();
  const { outcome } = await window.deferredInstallPrompt.userChoice;
  console.log(`User ${outcome} the install`);
}
```

## Delayed SW Registration [step]

Don't register SW until app is ready:

```typescript
function shouldRegisterSW(): boolean {
  return localStorage.getItem("app-ready") === "true";
}

if ("serviceWorker" in navigator) {
  window.addEventListener("load", async () => {
    if (shouldRegisterSW()) {
      await registerServiceWorker();
    }
  });
}
```

**Why delay?** Better UX — don't interrupt onboarding.

## Detect PWA Mode [step]

```typescript
function isRunningAsPWA(): boolean {
  return (
    window.matchMedia("(display-mode: standalone)").matches ||
    (navigator as any).standalone === true
  );
}
```

2. Verify manifest loads
3. Check install icon in address bar
4. Test offline mode
