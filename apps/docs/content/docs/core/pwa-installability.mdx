## Prerequisites

1. **HTTPS or localhost** — Required for SW and PWA
2. **Service Worker** — Already set up (see [Versioned SW](/docs/core/versioned-sw))
3. **Web App Manifest** — Describes your app

## Setup

### 1. Create Manifest

Create `public/manifest.json`:

```json
{
  "name": "My Offline App",
  "short_name": "MyApp",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#000000",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" }
  ]
}
```

### 2. Link in HTML

```html
<link rel="manifest" href="/manifest.json" />
<meta name="theme-color" content="#000000" />
```

### 3. Handle Install Prompt

```typescript
window.addEventListener("beforeinstallprompt", (e) => {
  e.preventDefault();
  window.deferredInstallPrompt = e as any;
});

async function promptInstall() {
  await window.deferredInstallPrompt?.prompt();
  const { outcome } = await window.deferredInstallPrompt.userChoice;
}
```

### 4. Detect PWA Mode

```typescript
function isRunningAsPWA(): boolean {
  return (
    window.matchMedia("(display-mode: standalone)").matches ||
    (navigator as any).standalone === true
  );
}
```

### 5. Generate Icons

Create icons at 192x192 and 512x512 minimum.

## Test PWA

1. DevTools → Application → Manifest
2. Verify manifest loads
3. Check install icon in address bar
4. Test offline mode

## Checklist

- [ ] Manifest created and linked
- [ ] Icons generated (192x192, 512x512)
- [ ] SW registered
- [ ] Offline works
- [ ] Install prompt works
