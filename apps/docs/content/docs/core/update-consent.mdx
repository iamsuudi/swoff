# Version Management

Handle updates with **consent-based versioning**.

## Overview

Users explicitly approve updates:

```
idle → available → downloading → (reload)
```

## How It Works

### Version Source

`package.json` version:

```json
{ "version": "1.0.0" }
```

### Build Output

```
dist/
├── sw-v1.0.0.js      ← Versioned SW
└── version.json        ← Version manifest
```

### Version Manifest

```json
{
  "version": "1.0.0",
  "forceUpdate": false
}
```

## Update Flow

```
Check version.json
  ↓
Same version? → Use existing SW
  ↓
New version? → Show update prompt → User approves → Download → Reload
```

## Update Prompt

```typescript
function UpdatePrompt() {
  const [status, setStatus] = useState<'idle' | 'available' | 'downloading'>('idle')

  useEffect(() => {
    window.addEventListener('sw-update-available', () => setStatus('available'))
  }, [])

  if (status === 'idle') return null

  return (
    <div>
      <p>Update available!</p>
      <button onClick={acceptUpdate}>Update</button>
    </div>
  )
}
```

## Force Updates

Set `forceUpdate: true` in `generate-sw.js`:

```javascript
writeFileSync('dist/version.json', JSON.stringify({
  version: pkg.version,
  forceUpdate: true  // User must update
}))
```

## Session Dismissal

Suppress dialog for current session:

```typescript
function dismissUpdate() {
  sessionStorage.setItem('sw-dismissed-update', 'true')
}
```

## Events

| Event | Purpose |
|-------|---------|
| `sw-update-available` | New version detected |
| `sw-progress` | Download progress |
| `sw-ready` | SW active |

## Window Properties

```typescript
interface Window {
  latestSWVersion?: string
  currentSWVersion?: string
  swForceUpdate?: boolean
}
```

## Bumping Versions

```bash
npm version patch  # 1.0.0 → 1.0.1
npm run build
```
