# Versioned Service Worker System

Swoff's core innovation is **versioning the service worker file itself**. This prevents browsers from silently updating your SW and gives users explicit control.

## The Problem with Traditional SW

Traditional PWA tutorials tell you to register `/sw.js`:

```javascript
navigator.serviceWorker.register('/sw.js')
```

The browser then:
1. Downloads `sw.js` when it changes
2. Installs it in the background
3. Activates it on next page reload

**This is dangerous.** If your new SW has breaking changes, users get them without consent.

## Swoff's Solution: Versioned Filenames

Instead of `/sw.js`, we use `/sw-v1.0.0.js`, `/sw-v1.0.1.js`, etc.

```
dist/
├── sw-v1.0.0.js      ← Version 1.0.0
├── sw-v1.0.1.js      ← Version 1.0.1
└── version.json        ← Version manifest
```

Each version is a **unique file**. The browser only loads the version you tell it to.

## How Versioning Works

### 1. Version from package.json

```json
{
  "name": "my-app",
  "version": "1.0.0"
}
```

### 2. Build Generates Versioned SW

```javascript
// generate-sw.js (build script)
import { readFileSync, writeFileSync } from 'fs'
import { fileURLToPath } from 'url'
import { join, dirname } from 'path'

const __dirname = dirname(fileURLToPath(import.meta.url))
const pkg = JSON.parse(readFileSync(join(__dirname, 'package.json'), 'utf8'))

const template = readFileSync(join(__dirname, 'src/sw-template.js'), 'utf8')
let sw = template.replace('// [[CACHE_NAME]]', `const CACHE_NAME = 'sw-v${pkg.version}'`)
sw = sw.replace('// [[ASSETS_LIST]]', `const ASSETS_TO_CACHE = ['/', '/index.html']`)

writeFileSync(join(__dirname, 'dist', `sw-v${pkg.version}.js`), sw)
writeFileSync(join(__dirname, 'dist', 'version.json'), JSON.stringify({
  version: pkg.version,
  generatedAt: new Date().toISOString(),
  forceUpdate: false
}))
```

### 3. Client Checks version.json

```javascript
// Check for updates
async function checkForUpdate() {
  const response = await fetch('/version.json')
  const manifest = await response.json()
  return manifest
}

// Register specific version
async function registerSpecificVersion(version) {
  const swUrl = `/sw-v${version}.js`
  const registration = await navigator.serviceWorker.register(swUrl)
  localStorage.setItem('swRegisteredVersion', version)
  return registration
}
```

## Update Flow

```
User opens app
    ↓
Fetch /version.json
    ↓
Compare with localStorage['swRegisteredVersion']
    ↓
Same version? → Use existing SW (do nothing)
    ↓
New version? → Fire 'sw-update-available' event
    ↓
Show update prompt to user
    ↓
User clicks "Update"
    ↓
Register new SW (sw-v1.0.1.js)
    ↓
New SW downloads assets in background
    ↓
Report progress via postMessage
    ↓
When complete → Send SKIP_WAITING
    ↓
New SW activates → Reload page
```

## Version Manifest (version.json)

```json
{
  "version": "1.0.1",
  "generatedAt": "2024-01-15T10:30:00.000Z",
  "forceUpdate": false
}
```

| Field | Purpose |
|-------|---------|
| `version` | SemVer version string |
| `generatedAt` | ISO timestamp of build |
| `forceUpdate` | If true, force update (future use) |

## SW Template

The SW template uses placeholders that get replaced during build:

```javascript
// src/sw-template.js
// [[CACHE_NAME]]
// [[ASSETS_LIST]]

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then(cache =>
      cache.addAll(ASSETS_TO_CACHE)
    )
  )
})

self.addEventListener('fetch', (event) => {
  if (event.request.method !== 'GET') return
  event.respondWith(
    caches.match(event.request).then(cached =>
      cached || (event.request.mode === 'navigate'
        ? caches.match('/index.html')
        : fetch(event.request))
    )
  )
})

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then(keys =>
      Promise.all(
        keys.filter(k => k !== CACHE_NAME).map(k => caches.delete(k))
      )
    )
  )
})
```

## Benefits

1. **No silent updates** — users explicitly approve
2. **Rollback possible** — just re-register old version
3. **Clear versioning** — filename shows exact version
4. **Browser agnostic** — works in all browsers with SW support
