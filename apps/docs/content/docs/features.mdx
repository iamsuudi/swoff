# Features

Swoff is copy-paste code you own. No npm packages. No library updates that break your app.

## Three Tiers

### Required Core

Copy these 4 files into your project:

| File | Purpose |
|------|---------|
| [SW Template](/docs/patterns/sw-template) | Versioned service worker with caching strategies |
| [Build Scripts](/docs/patterns/build-scripts) | Generate versioned SW + version.json |
| [Client Registration](/docs/patterns/client-registration) | SW registration with update consent |
| [API Integration](/docs/patterns/api-integration) | Fetch wrapper with cache strategy headers |

### Optional

Add as needed:

| File | Purpose |
|------|---------|
| [PWA Installability](/docs/patterns/pwa-installability) | Manifest, install prompt, standalone mode |
| [IndexedDB Patterns](/docs/patterns/indexeddb-patterns) | DB setup, CRUD, migrations, quota management |

### Advanced

Production patterns — each independent:

| File | Purpose |
|------|---------|
| [Mutation Queuing](/docs/advanced/mutation-queuing) | Queue offline writes, sync on reconnect |
| [Background Sync](/docs/advanced/background-sync) | Sync after tab close (Chrome/Edge) |
| [Conflict Resolution](/docs/advanced/conflict-resolution) | LWW, custom merge, manual, CRDT |
| [Auth Stack](/docs/advanced/authentication) | Token storage, auth-aware fetch, lock screen |
| [Testing](/docs/advanced/testing) | Vitest + fake-indexeddb + Playwright |
| [Debugging](/docs/advanced/debugging) | DevTools, postMessage monitoring |

## Swoff vs Traditional PWA Libraries

| | Swoff | Traditional PWA Libraries |
|--|-------|---------------------------|
| Dependencies | Zero runtime deps | npm packages |
| Control | You own the code | Library updates can break your app |
| Updates | Consent-based, versioned | Often automatic |
| Offline | Guaranteed by architecture | Depends on library |
| Framework | Agnostic | Often framework-specific |

## Build Your Stack

| Stack | Files | Use case |
|-------|-------|----------|
| **Minimal** | SW Template + Build Scripts + Client Registration | Versioned SW updates only |
| **Standard** | Above + API Integration + IndexedDB | Offline reads, cached data |
| **Full Client Runtime** | Above + Mutation Queuing + Conflict Resolution | Offline reads + queued writes with sync |
| **Full + Auth** | Above + Auth Stack | Offline app with auth |
