# Django & Flask / Python

Swoff works with any Python backend. The generated files are static — serve them however you serve your other assets. No Node.js runtime needed in production.

## Config per flavor

| Setting               | Django                 | Flask                 |
| --------------------- | ---------------------- | --------------------- |
| `build.outputDir`     | `"static"`             | `"static"`            |
| `build.swFilename`    | `"sw"`                 | `"sw"`                |
| `navigation.mode`     | `"ssr"`                | `"ssr"`               |
| `navigation.fallback` | `"/offline"`           | `"/offline"`          |
| `navigation.preload`  | `true`                 | `true`                |
| `strategy.default`    | `"network-first"`      | `"network-first"`     |

- **`navigation.mode: "ssr"`** — server-rendered HTML pages get cached individually

## Where to place generated files

After `swoff generate`, make the `swoff/` directory accessible to your app.

### Django

```bash
# Place directly in your static directory
cp -r swoff your_app/static/swoff/

# Or symlink from a static directory
ln -s /full/path/to/swoff your_app/static/swoff

# Then run collectstatic:
python manage.py collectstatic
```

### Flask

Flask serves `static/` automatically — just copy or generate directly into it:

```bash
cp -r swoff static/swoff/
# Or configure swoff.config.json build.outputDir to point into your Flask app:
#   "outputDir": "your_app/static"
```

## Entry point

Include the client-injector script in your template:

### Django

```jinja
{% load static %}

<body>
  {% block content %}{% endblock %}

  <script src="{% static 'swoff/client-injector.bundle.js' %}"></script>
</body>
```

### Flask

```html
<body>
  {% block content %}{% endblock %}

  <script src="{{ url_for('static', filename='swoff/client-injector.bundle.js') }}"></script>
</body>
```

## Build script

Add the SW generator to your build pipeline. Requires Node.js only at build time:

### Django

```bash
# In CI or deployment script:
npm run build  # if using Vite/webpack
node swoff/sw/generator.js
python manage.py collectstatic
```

Without a JS build step:

```bash
node swoff/sw/generator.js
python manage.py collectstatic
```

### Flask

Flask has no `collectstatic` equivalent — generated files go straight into `static/`:

```bash
node swoff/sw/generator.js
```

If your `swoff.config.json` has `outputDir` pointing to Flask's static folder, run only the generator.

## Auth

Both Django and Flask use cookie-based session auth — the generated `auth/adapter.ts` works out of the box. Cookies are sent automatically by the browser.

```json
{
  "features": {
    "auth": {
      "enabled": true,
      "type": "cookie",
      "routePaths": ["/login", "/logout", "/admin/*"]
    }
  }
}
```
