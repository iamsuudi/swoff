# Go

Swoff works with any Go backend. The generated files are static — embed them or serve from a static directory.

## Config per flavor

| Setting               | Go (net/http / chi / gin) |
| --------------------- | ------------------------- |
| `build.outputDir`     | `"static"` or `"public"`  |
| `build.swFilename`    | `"sw"`                    |
| `navigation.mode`     | `"ssr"`                   |
| `navigation.fallback` | `"/offline"`              |
| `navigation.preload`  | `true`                    |
| `strategy.default`    | `"network-first"`         |

## Where to place generated files

```bash
# Generate swoff files, then copy to your static directory:
cp -r swoff static/swoff
```

Embed them in your Go binary for single-binary deployment:

```go
package main

import (
  "embed"
  "net/http"
)

//go:embed static/swoff/*
var swoffFS embed.FS

func main() {
  // Serve swoff files
  http.Handle("/swoff/", http.FileServer(http.FS(swoffFS)))
  http.ListenAndServe(":8080", nil)
}
```

Or serve from disk with chi/gin:

```go
// chi
r.Handle("/swoff/*", http.StripPrefix("/swoff/",
  http.FileServer(http.Dir("static/swoff"))))

// gin
r.Static("/swoff", "./static/swoff")
```

## Entry point

In your HTML template (Go `html/template`):

```html
<body>
  {{template "content" .}}

  <script src="/swoff/client-injector.bundle.js"></script>
</body>
```

## Build script

Add the SW generator to your Makefile or CI:

```makefile
build:
	go build -o app .
	node swoff/sw/generator.js
```

## Auth

For cookie-based auth (e.g., session middleware):

```json
{
  "features": {
    "auth": {
      "enabled": true,
      "type": "cookie",
      "routePaths": ["/login", "/logout", "/api/auth/*"]
    }
  }
}
```

Cookie auth works with background sync and server push.
