# Framework Integration

## Quick Start

Swoff works with any framework. The steps are the same regardless of your stack:

```bash
# 1. Initialize config (npx downloads the CLI — no package.json needed)
npx @swoff/cli init
```

```bash
# 2. Enable features in the config
vim swoff.config.json
```

```bash
# 3. Generate all files
npx @swoff/cli generate
```

Step 4 depends on your framework — the CLI detects whether you use a bundler:

**No bundler (vanilla, Laravel, Django, Flask, Rails, Go, HTMX):** use the auto-initializing bundle:

```html
<script src="/swoff/client-injector.bundle.js"></script>
```

**Bundler framework (React, Vue, Svelte, Astro, Nuxt, Next.js, Remix):** import the modular injector:

```ts
import { initServiceWorker } from "./swoff/client-injector";
initServiceWorker();
```

```bash
# 5. Build the final service worker (run after your build)
node swoff/sw/generator.js
```

For Node.js projects, add it to your build script:

```json
{
  "scripts": {
    "build": "your-build && node swoff/sw/generator.js"
  }
}
```

```ts
// 6. (Bundler frameworks only) Use adapters from swoff/adapters/
import { useCachedFetch } from "./swoff/adapters/useCachedFetch";
```

The only framework-specific differences are:

- **`swoff.config.json` values** — `build.outputDir`, `navigation.mode`, `fallback`, `precacheDirs`, `ignorePatterns`
- **Adapters** — Bundler frameworks (React, Vue, Svelte, etc.) get generated hooks; other ecosystems use window events or header overrides (see per-ecosystem pages)
