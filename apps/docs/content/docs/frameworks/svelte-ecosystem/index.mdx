## Svelte Ecosystem

All Svelte-based frameworks share the same adapter layer — stores and components. The only difference is where you inject the files.

## Available Guides

| Framework                                                  | Description                          |
| ---------------------------------------------------------- | ------------------------------------ |
| [Svelte + Vite](/docs/frameworks/svelte-ecosystem/svelte-vite) | Plain Svelte 5 with Vite             |
| [SvelteKit](/docs/frameworks/svelte-ecosystem/sveltekit)       | Svelte full-stack (client-only mode) |

## Shared Adapter Layer

- **[Svelte Stores](/docs/frameworks/svelte-ecosystem/stores)** — `pwaUpdate`, `swProgress`, `pwaVersion`
- **[Svelte Components](/docs/frameworks/svelte-ecosystem/components)** — `UpdatePrompt`, `SWProgressBar`, `InstallButton`
