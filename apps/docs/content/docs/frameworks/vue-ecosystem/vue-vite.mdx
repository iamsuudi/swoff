## Vue + Vite

Concise adapter for **Vue 3 + Vite** projects.

## Create Project

```bash
npm create vite@latest my-app -- --template vue-ts
cd my-app && npm install
```

## Project Structure

```
my-app
├── src
│   └── main.ts
├── swoff
│   ├── sw-template.js
│   ├── sw-generator.js
│   ├── sw-injector.js
│   └── swoff.d.ts
└── package.json
```

## Entry Point (`src/main.ts`)

```typescript
import { createApp } from "vue";
import App from "./App.vue";
import { initServiceWorker } from "../swoff/sw-injector";

initServiceWorker();

createApp(App).mount("#app");
```

## Add Patterns

Copy from [Patterns](/docs/cli/):

1. **[SW Template](/docs/architecture/architecture)** → `swoff/sw-template.js`
2. **[Build Script](/docs/cli/)** → `swoff/sw-generator.js` (output dir: `dist/`)
3. **[Client Registration](/docs/cli/)** → `swoff/sw-injector.js`
4. **[TypeScript Declarations](/docs/cli/)** → `swoff/swoff.d.ts`

Update `package.json`:

```json
{
  "scripts": {
    "build": "vite build && node swoff/sw-generator.js"
  }
}
```

## Output Directory

Vite outputs to `dist/` by default. Your `swoff/sw-generator.js` should write to `dist/`.

## Build & Test

```bash
npm version patch
npm run build
```
