# Vue

Vue adapters (composables) are not yet generated by the CLI. See the [Blueprint](/docs/frameworks/blueprint) to create them for your project.

## Config per flavor

| Setting | Vue + Vite | Nuxt |
|---|---|---|
| `build.outputDir` | `"dist"` | `"dist"` |
| `build.swFilename` | `"sw"` | `"sw"` |
| `navigation.mode` | `"spa"` | `"spa"` |
| `navigation.fallback` | `"/index.html"` | `"/index.html"` |
| `navigation.preload` | `true` | `true` |

Nuxt generates a client-side bundle in `.nuxt/dist/client/`. Set `build.precacheDirs` to include that directory if you want to precache the app shell.

## Entry point

```ts
import { initServiceWorker } from "./swoff/client-injector";

onMounted(() => { initServiceWorker(); });
```

For Nuxt, call `initServiceWorker` in a client-only plugin or in `app.vue` wrapped in `onMounted`.

## Build script

Run the SW generator after your build:

```bash
node swoff/sw/generator.js
```

Or add it to `package.json`:

```json
{
  "scripts": {
    "build": "your-build && node swoff/sw/generator.js"
  }
}
```

## Adapters

Once you create adapters via the [Blueprint](/docs/frameworks/blueprint), import them like:

```ts
import { useCachedFetch } from "./swoff/adapters/useCachedFetch";
```

The naming convention is the same across all frameworks — the adapter layer maps window events to your framework's reactive system.
