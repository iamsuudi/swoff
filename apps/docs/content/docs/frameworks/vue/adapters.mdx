# Vue

Swoff works with any Vue-based project. Vue adapters (composables) are not yet generated by the CLI, but all window events are available for manual integration. See the [Blueprint](/docs/frameworks/blueprint) to create composables for your project.

## Config per flavor

| Setting               | Vue + Vite      | Nuxt            |
| --------------------- | --------------- | --------------- |
| `build.outputDir`     | `"dist"`        | `"dist"`        |
| `build.swFilename`    | `"sw"`          | `"sw"`          |
| `navigation.mode`     | `"spa"`         | `"spa"`         |
| `navigation.fallback` | `"/index.html"` | `"/index.html"` |
| `navigation.preload`  | `true`          | `true`          |

Nuxt generates a client-side bundle in `.nuxt/dist/client/`. Set `build.precacheDirs` to include that directory if you want to precache the app shell.

## Entry point

```ts
import { initServiceWorker } from "./swoff/client-injector";

onMounted(() => {
  initServiceWorker();
});
```

For Nuxt, call `initServiceWorker` in a client-only plugin or in `app.vue` wrapped in `onMounted`.

## Window events (no adapter needed)

The SW broadcasts lifecycle events as `window` custom events. Listen for them directly in any Vue component:

```vue
<script setup>
import { onMounted, onUnmounted, ref } from "vue";

const swReady = ref(false);

function onSwReady() {
  swReady.value = true;
}

onMounted(() => {
  window.addEventListener("sw-ready", onSwReady);
});

onUnmounted(() => {
  window.removeEventListener("sw-ready", onSwReady);
});
</script>
```

All [Blueprint events](/docs/frameworks/blueprint#window-events) work the same way — `sw-update-available`, `sw-auth-state-change`, `cache-invalidated`, `mutation-queue-changed`, and more.

## Build script

Run the SW generator after your build:

```bash
node swoff/sw/generator.js
```

Or add it to `package.json`:

```json
{
  "scripts": {
    "build": "your-build && node swoff/sw/generator.js"
  }
}
```

## Adapters (composables)

Once you create composables via the [Blueprint](/docs/frameworks/blueprint), import them like:

```ts
import { useCachedFetch } from "./swoff/adapters/useCachedFetch";
```

The naming convention is the same across all frameworks — the adapter layer maps window events to your framework's reactive system. The [Blueprint](/docs/frameworks/blueprint) shows the complete event map and a template for creating Vue composables.
