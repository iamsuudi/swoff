# Introduction

Swoff is a CLI toolbox that generates offline-first infrastructure for your web app. No runtime dependencies — you own the generated code.

## Why Swoff?

- **Config-driven** — toggle features in `swoff.config.json`, the CLI generates everything
- **Zero runtime deps** — the generated files are all you need, no library version conflicts
- **Two output modes** — bundler frameworks (React, Vue, Svelte, etc.) get modular ES imports with full API access; vanilla and server-rendered frameworks (Laravel, Django, Flask, Rails, Go, HTMX) get a self-contained IIFE bundle that auto-initializes on load
- **Framework-agnostic** — React, Vue, Svelte, Laravel, Django, Flask, Rails, Go, HTMX, or vanilla HTML
