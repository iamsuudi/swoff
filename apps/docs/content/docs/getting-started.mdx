# Introduction

Swoff generates offline-first infrastructure from a single config file — a service worker, client utilities, and React hooks. No runtime dependencies.

## Why Swoff?

- **Config-driven** — features controlled via config, code is generated
- **Zero runtime deps** — generated files are all you need, no library conflicts
- **Two output modes** — ES modules + hooks for bundlers, auto-initializing bundle otherwise
- **Framework-agnostic** — React, Vue, Svelte, Laravel, Django, Rails, Go, HTMX, vanilla
