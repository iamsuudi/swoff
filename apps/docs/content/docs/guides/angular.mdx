# Angular

Concise adapter for **Angular** projects.

## Create Project

```bash
ng new my-app --style=scss --routing
cd my-app && npm install
```

## Project Structure

```
my-app
├── src
│   ├── main.ts
│   └── sw-template.js
├── generate-sw.js
├── sw.d.ts
└── package.json
```

## Entry Point (`src/main.ts`)

Add SW registration to Angular's entry point:

```typescript
import { platformBrowserDynamic } from "@angular/platform-browser-dynamic";
import { AppModule } from "./app/app.module";

async function registerSW() {
  const { version } = await fetch("/version.json").then((r) => r.json());
  await navigator.serviceWorker.register(`/sw-v${version}.js`);
}

if ("serviceWorker" in navigator) {
  window.addEventListener("load", registerSW);
}

platformBrowserDynamic()
  .bootstrapModule(AppModule)
  .catch((err) => console.error(err));
```

## Add Patterns

Copy these files from [Patterns](/docs/patterns):

1. **[SW Template](/docs/patterns/sw-template)** → `src/sw-template.js`
2. **[Build Script](/docs/patterns/build-scripts)** → `generate-sw.js` (adapt for Angular's build)
3. **[Client Registration](/docs/patterns/client-registration)** → `src/sw-registration.ts`
4. **[TypeScript Declarations](/docs/patterns/utilities)** → `sw.d.ts`

Update `package.json`:

```json
{
  "scripts": {
    "build": "ng build && node generate-sw.js"
  }
}
```

## Note on Angular Service Worker

Angular has its own `@angular/service-worker` package. Swoff's approach is different:

- **Angular SW**: Opinionated, tied to Angular
- **Swoff SW**: Framework-agnostic, you own the code, versioned with consent

Use Swoff's SW template instead of Angular's built-in SW for full control.
