## Angular

Concise adapter for **Angular** projects.

## Create Project

```bash
ng new my-app --style=scss --routing
cd my-app && npm install
```

## Project Structure

```
my-app
├── src
│   ├── main.ts
│   └── sw-template.js
├── generate-sw.js
├── sw.d.ts
└── package.json
```

## Entry Point (`src/main.ts`)

```typescript
import { platformBrowserDynamic } from "@angular/platform-browser-dynamic";
import { AppModule } from "./app/app.module";
import { initServiceWorker } from "./sw-registration";

initServiceWorker();

platformBrowserDynamic()
  .bootstrapModule(AppModule)
  .catch((err) => console.error(err));
```

## Add Patterns

Copy from [Patterns](/docs/patterns):

1. **[SW Template](/docs/patterns/sw-template)** → `src/sw-template.js`
2. **[Build Script](/docs/patterns/build-scripts)** → `generate-sw.js` (output dir: `dist/my-app/`)
3. **[Client Registration](/docs/patterns/client-registration)** → `src/sw-registration.ts`
4. **[TypeScript Declarations](/docs/patterns/utilities)** → `sw.d.ts`

Update `package.json`:

```json
{
  "scripts": {
    "build": "ng build && node generate-sw.js"
  }
}
```

## Output Directory

Angular outputs to `dist/<project-name>/` by default. Update your `generate-sw.js`:

```javascript
writeFileSync(join(__dirname, "dist", "my-app", `sw-v${pkg.version}.js`), sw);
writeFileSync(join(__dirname, "dist", "my-app", "version.json"), JSON.stringify({ ... }));
```

## Note on Angular Service Worker

Angular has its own `@angular/service-worker` package. Swoff's approach is different — you own the code, it's versioned, and updates require user consent.

## Build & Test

```bash
npm version patch
npm run build
```
