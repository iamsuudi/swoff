# Contributing Adapters

Swoff is framework agnostic. We rely on the community to write **concise adapters** for different frameworks.

## What is an Adapter?

An adapter is a short guide showing **where to plug Swoff patterns** into a specific framework.

**Key principle**: Don't repeat patterns — link to them. Adapters are 50-80 lines max.

## How to Contribute

### 1. Fork & Create File

```bash
git clone https://github.com/iamsuudi/swoff.git
cd swoff

# Example: Nuxt adapter
mkdir -p apps/docs/content/docs/guides/vue
touch apps/docs/content/docs/guides/vue/nuxt.mdx
```

### 2. Follow the Concise Template

```mdx
---
title: Nuxt
description: Set up Swoff with Nuxt.
icon: Nuxt
---

# Nuxt

Concise adapter for **Nuxt 3** projects.

## Create Project

```bash
npx nuxi@latest init my-app
cd my-app && npm install
```

## Project Structure

```
my-app
├── app
│   └── sw-template.js
├── generate-sw.js
├── sw.d.ts
└── package.json
```

## Entry Point

Add SW registration to Nuxt's plugin system (see [Client Registration](/docs/patterns/client-registration)):

```typescript
// plugins/sw.client.ts
export default defineNuxtPlugin(() => {
  if ('serviceWorker' in navigator) {
    window.addEventListener('load', async () => {
      const { version } = await fetch('/version.json').then(r => r.json())
      await navigator.serviceWorker.register(`/sw-v${version}.js`)
    })
  }
})
```

## Add Patterns

Copy from [Patterns](/docs/patterns):

1. **[SW Template](/docs/patterns/sw-template)** → `app/sw-template.js`
2. **[Build Script](/docs/patterns/build-scripts)** → `generate-sw.js`
3. **[TypeScript Declarations](/docs/patterns/utilities)** → `sw.d.ts`

Update `package.json`:
```json
{
  "scripts": {
    "build": "nuxt build && node generate-sw.js"
  }
}
```

## Build & Test

```bash
npm version patch
npm run build

### 3. Update meta.json

Add to `apps/docs/content/docs/guides/vue/meta.json`:

```json

  "pages": ["index", "vue-vite", "nuxt"]

```bash

# Visit http://localhost:3000/docs/guides/vue/nuxt
```

### 5. Submit PR

```bash
git checkout -b feat/nuxt-adapter
git add .
git commit -m "Add Nuxt adapter guide"
git push origin feat/nuxt-adapter
```

## Guidelines

1. **Keep it concise** — 50-80 lines max (excluding code blocks)
2. **Link, don't repeat** — Reference `/docs/patterns/*`, don't paste pattern code
3. **Show the entry point** — Where does SW registration go in this framework?
4. **Framework-specific tweaks only** — Project creation, file structure, entry point
5. **Test it** — Follow your own guide to verify it works

## Adapter Structure (Cheat Sheet)

```
1. Title + description (frontmatter)
2. ## Create Project (one command)
3. ## Project Structure (tree view)
4. ## Entry Point (where to register SW)
5. ## Add Patterns (list 3-4 pattern links)
6. ## Build & Test (2-3 commands)
7. ## Next Steps (3 pattern/core links)
```

## What NOT to Include

- ❌ SW template code (link to [SW Template](/docs/patterns/sw-template))
- ❌ Build script code (link to [Build Scripts](/docs/patterns/build-scripts))
- ❌ Client registration logic (link to [Client Registration](/docs/patterns/client-registration))
- ❌ TypeScript declarations (link to [Utilities](/docs/patterns/utilities))
- ❌ Hook implementations (link to [Update Hooks](/docs/patterns/update-hooks))
