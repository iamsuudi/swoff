## Configuration

All framework guides now use the new JSON configuration system:

```json
{
  "$schema": "https://swoff.ai/schema/v1.json",
  "enabled": true,
  "version": "from-package",
  "serviceWorker": {
    "defaultStrategy": "cache-first",
    "strategies": {
      "/api/*": "network-first",
      "/static/*": "cache-first"
    }
  },
  "features": {
    "offlineReads": true,
    "mutationQueue": true,
    "pwa": true
  }
}
```
