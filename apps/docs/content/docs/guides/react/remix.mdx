# Remix

Concise adapter for **Remix** in client-side mode.

## Important: Client-Side Mode

Remix is fullstack, but Swoff is **client-side only**. Use Remix for routing only:

- Deploy as static files (no Remix server)
- Skip server loaders/actions for offline-first
- Your backend is separate (Go, Node.js, Python, etc.)

## Create Project

```bash
npx create-remix@latest my-app
cd my-app && npm install
```

## Project Structure

```
my-app
├── app
│   ├── root.tsx
│   └── sw-template.js
├── generate-sw.js
├── sw.d.ts
└── package.json
```

## Entry Point (`app/root.tsx`)

```typescript
import { Outlet } from '@remix-run/react'

async function registerSW() {
  const { version } = await fetch('/version.json').then(r => r.json())
  await navigator.serviceWorker.register(`/sw-v${version}.js`)
}

if (typeof window !== 'undefined' && 'serviceWorker' in navigator) {
  window.addEventListener('load', registerSW)
}

export default function App() {
  return <Outlet />
}
```

## Build & Test

```bash
npm version patch
npm run build
```

## Note on Remix Server

Remix's server features (loaders, actions) are for your backend. Since Swoff is client-only:

- Skip server-side rendering if targeting offline-first
- Or use loaders only for online data fetching (your backend)
