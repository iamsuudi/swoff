# TanStack Start + Vite

Setup for **TanStack Start** projects with client-only mode.

## Install TanStack Start

```bash
npm install @tanstack/react-start @tanstack/react-router
npm install -D @tanstack/router-plugin
```

## Configure Vite

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { tanstackStart } from '@tanstack/router-plugin/vite'

export default defineConfig({
  plugins: [tanstackStart(), react()],
})
```

## Disable SSR

For offline-first, use client-only:

```typescript
// app.config.ts
export default defineConfig({
  ssr: false, // ← Important for offline
})
```

## Update main.tsx

```typescript
import React from 'react'
import ReactDOM from 'react-dom/client'
import { RouterProvider } from '@tanstack/react-router'
import router from './router'

async function registerSW() {
  const { version } = await fetch('/version.json').then(r => r.json())
  await navigator.serviceWorker.register(`/sw-v${version}.js`)
}

if ('serviceWorker' in navigator) {
  window.addEventListener('load', registerSW)
}

ReactDOM.createRoot(document.getElementById('app')!).render(
  <RouterProvider router={router} />
)
```

```bash
npm version patch
npm run build
```

## Notes

- Set `ssr: false` for offline-first — Swoff runs client-only
- All logic runs in browser via Service Worker + IndexedDB
- TanStack Start's server API routes are not used (Swoff is client-side only)
