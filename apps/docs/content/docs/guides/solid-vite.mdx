# SolidJS + Vite

Concise adapter for **SolidJS + Vite** projects.

## Create Project

```bash
npm create vite@latest my-app -- --template solid-ts
cd my-app && npm install
```

## Project Structure

```
my-app
├── src
│   ├── index.tsx
│   └── sw-template.js
├── generate-sw.js
├── sw.d.ts
└── package.json
```

## Entry Point (`src/index.tsx`)

Add SW registration to Solid's entry point:

```typescript
import { render } from 'solid-js/web'
import App from './App'

async function registerSW() {
  const { version } = await fetch('/version.json').then(r => r.json())
  await navigator.serviceWorker.register(`/sw-v${version}.js`)
}

if ('serviceWorker' in navigator) {
  window.addEventListener('load', registerSW)
}

render(() => <App />, document.getElementById('root')!)
```

## Add Patterns

Copy these files from [Patterns](/docs/patterns):

1. **[SW Template](/docs/patterns/sw-template)** → `src/sw-template.js`
2. **[Build Script](/docs/patterns/build-scripts)** → `generate-sw.js`
3. **[Client Registration](/docs/patterns/client-registration)** → `src/sw-registration.js`
4. **[TypeScript Declarations](/docs/patterns/utilities)** → `sw.d.ts`

Update `package.json`:
```json
{
  "scripts": {
    "build": "vite build && node generate-sw.js"
  }
}
```

