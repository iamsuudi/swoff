## SolidJS + Vite

Concise adapter for **SolidJS + Vite** projects.

## Create Project

```bash
npm create vite@latest my-app -- --template solid-ts
cd my-app && npm install
```

## Project Structure

```
my-app
├── src
│   └── index.tsx
├── swoff
│   ├── sw-template.js
│   ├── sw-generator.js
│   ├── sw-injector.js
│   └── swoff.d.ts
└── package.json
```

## Entry Point (`src/index.tsx`)

```typescript
import { render } from 'solid-js/web'
import App from './App'
import { initServiceWorker } from '../swoff/sw-injector'

initServiceWorker()

render(() => <App />, document.getElementById('root')!)
```

## Add Patterns

Copy from [Patterns](/docs/patterns):

1. **[SW Template](/docs/patterns/sw-template)** → `swoff/sw-template.js`
2. **[Build Script](/docs/patterns/build-scripts)** → `swoff/sw-generator.js` (output dir: `dist/`)
3. **[Client Registration](/docs/patterns/client-registration)** → `swoff/sw-injector.js`
4. **[TypeScript Declarations](/docs/patterns/client-registration#typescript-declarations)** → `swoff/swoff.d.ts`

Update `package.json`:

```json
{
  "scripts": {
    "build": "vite build && node swoff/sw-generator.js"
  }
}
```

## Output Directory

Vite outputs to `dist/` by default.

## Build & Test

```bash
npm version patch
npm run build
```
