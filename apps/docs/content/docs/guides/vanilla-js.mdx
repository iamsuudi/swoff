## Vanilla JavaScript

Swoff's patterns are based on browser APIs, so vanilla JS is the most natural fit.

## Project Structure

```
my-app/
├── index.html
├── app.js
├── sw-registration.js
├── sw-template.js
├── generate-sw.js
└── package.json
```

## HTML Entry Point (`index.html`)

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My App</title>
    <link rel="manifest" href="/manifest.json" />
  </head>
  <body>
    <div id="app"></div>
    <script src="app.js"></script>
  </body>
</html>
```

## Registration (`app.js`)

```javascript
import { initServiceWorker } from "./sw-registration.js";

initServiceWorker();

// Your app code here...
```

## Add Patterns

Copy from [Patterns](/docs/patterns):

1. **[SW Template](/docs/patterns/sw-template)** → `sw-template.js`
2. **[Build Script](/docs/patterns/build-scripts)** → `generate-sw.js`
3. **[Client Registration](/docs/patterns/client-registration)** → `sw-registration.js`

For a build tool (optional):

```bash
npm create vite@latest my-app -- --template vanilla-ts
```

Update `package.json`:

```json
{
  "scripts": {
    "build": "vite build && node generate-sw.js"
  }
}
```

## Output Directory

- Plain HTML: serve from project root, `generate-sw.js` writes to project root
- With Vite: outputs to `dist/`

## No Framework Needed

Swoff uses standard browser APIs — Service Worker, IndexedDB, Cache API, Fetch API. Vanilla JS works natively with all of them.

## Build & Test

```bash
npm version patch
npm run build
```
