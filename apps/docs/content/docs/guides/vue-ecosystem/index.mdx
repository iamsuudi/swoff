## Vue Ecosystem

All Vue-based frameworks share the same adapter layer — composables and components. The only difference is where you inject the files.

## Shared Adapter Layer

- **[Vue Composables](/docs/guides/vue-ecosystem/composables)** — `usePWAUpdate`, `useSWProgress`, `usePWAVersion`
- **[Vue Components](/docs/guides/vue-ecosystem/components)** — `UpdatePrompt`, `SWProgressBar`, `InstallButton`
