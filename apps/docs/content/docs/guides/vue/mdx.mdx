# Vue + Vite (MDX)

Concise adapter for **Vue 3 + Vite** with MDX support.

## Create Project

```bash
npm create vite@latest my-app -- --template vue-ts
cd my-app && npm install
npm install -D @mdx-js/rollup
```

## Project Structure

```
my-app
├── src
│   ├── main.ts
│   └── sw-template.js
├── generate-sw.js
├── sw.d.ts
└── package.json
```

## Entry Point (`src/main.ts`)

Same as [Vue + Vite](/docs/guides/vue/vue-vite).

## Add Patterns

Copy from [Patterns](/docs/patterns):

1. **[SW Template](/docs/patterns/sw-template)** → `src/sw-template.js`
2. **[Build Script](/docs/patterns/build-scripts)** → `generate-sw.js`
3. **[TypeScript Declarations](/docs/patterns/utilities)** → `sw.d.ts`

## Build & Test

```bash
npm version patch
npm run build
```
