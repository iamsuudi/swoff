# Nuxt

Concise adapter for **Nuxt 3** (Vue 3) in client-only mode.

## Important: Client-Only Mode

Nuxt is fullstack, but Swoff is **client-side only**. Disable SSR:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  ssr: false, // Client-side only
})
```

## Create Project

```bash
npx nuxi@latest init my-app
cd my-app && npm install
```

## Project Structure

```
my-app
├── app
│   └── sw-template.js
├── generate-sw.js
├── sw.d.ts
└── package.json
```

## Entry Point (Plugin)

Create `plugins/sw.client.ts`:

```typescript
export default defineNuxtPlugin(() => {
  async function registerSW() {
    const { version } = await fetch('/version.json').then(r => r.json())
    await navigator.serviceWorker.register(`/sw-v${version}.js`)
  }

  if ('serviceWorker' in navigator) {
    window.addEventListener('load', registerSW)
  }
})
```

## Add Patterns

Copy from [Patterns](/docs/patterns):

1. **[SW Template](/docs/patterns/sw-template)** → `app/sw-template.js`
2. **[Build Script](/docs/patterns/build-scripts)** → `generate-sw.js`
3. **[TypeScript Declarations](/docs/patterns/utilities)** → `sw.d.ts`

Update `package.json`:
```json
{
  "scripts": {
    "build": "nuxt build && node generate-sw.js"
  }
}
```

## Build & Test

```bash
npm version patch
npm run build
```

Output in `.output/public/` folder — deploy static files.

## Note on Nuxt Server

Nuxt's server routes (`server/api/`) are for your backend. Since Swoff is client-only:

- Skip server routes if targeting offline-first
- Or use them for your own backend API
