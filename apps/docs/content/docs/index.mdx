## The Problem with Modern Web Tooling

Web frameworks have shifted toward server-side rendering and backend integration (Next.js, Nuxt, etc.), leaving client-side browser APIs underutilized. Meanwhile:

- Modern browsers offer powerful APIs (Service Worker, IndexedDB, Cache API, WebRTC, etc.) that rival native apps.
- State management libraries (Redux, Tanstack Query) are often framework-specific, causing lock-in.

## The Gap

Most tools ignore or abstract away client-side capabilities, focusing on server-side features instead. This leaves developers without a clear path to build offline-first, native-like web apps that leverage the browser's full potential.

## Why Swoff?

Swoff is a framework-agnostic, zero-dependency blueprint for client-first web apps. It's code you own, not an npm package:

- Copy patterns, adapters, and utilities directly into your project
- Modify them to fit your needs (no waiting for library updates)
- Pair with any framework (React, Vue, Svelte, vanilla JS)
- Build offline-first, installable PWAs that feel native

## Vision

A future where web apps match native software performance and features, accessible via URL with no app store friction.

:::success
Developers ship updates instantly, users get them immediately — no controlled native release cycles.
:::
