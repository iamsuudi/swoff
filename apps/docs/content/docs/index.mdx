Swoff generates offline-first infrastructure for your web app — the CLI produces a Service Worker and client code from a single config file, with zero runtime dependencies. You own every generated file; no library version conflicts, no hidden breakage.

```bash
npx @swoff/cli init --framework vanilla
npx @swoff/cli generate
```
