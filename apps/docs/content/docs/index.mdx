# Swoff

**Service Worker & Offline** — A zero-dependency blueprint for building offline-first web applications that feel like native apps.

## What is Swoff?

Swoff provides patterns, code snippets, and architecture guides to build web apps with:

- **Guaranteed offline capability** — Versioned service worker with asset caching
- **Zero runtime dependencies** — We give you code, not npm packages
- **User-consented updates** — No silent SW updates, users control when to update
- **Framework agnostic** — Works with React, Vue, Svelte, or vanilla JS
- **Installable** — PWA-ready with manifest and install prompts

## Philosophy

> "We provide code, not dependencies."

Swoff is not a traditional library. We don't ship an npm package you install. Instead:

1. **Learn the concepts** — Understand offline-first architecture step by step
2. **Copy our patterns** — Take our service worker, hooks, and utilities into your project
3. **Own your code** — Modify, extend, and maintain it yourself

## Why Swoff?

Modern browsers give us powerful APIs: Service Worker, IndexedDB, Cache API, Fetch, Push, Background Sync. Most frameworks ignore them or abstract them away.

Swoff brings them to the forefront:

- **Offline capability** through architecture, not caching tricks
- **Versioned updates** with user consent (not browser auto-updates)
- **Client-first** apps that work without a backend
- **Native feel** with installable PWAs and shortcuts

## Key Features

### Versioned Service Worker

Each build generates a uniquely versioned service worker (`sw-v1.0.0.js`, `sw-v1.0.1.js`, etc.). This prevents browsers from silently updating your SW and gives users control over when to update.

### Consent-Based Updates

Users explicitly approve updates. No surprise reloads. The update flow:
- Detect new version → Show update prompt → User accepts → Download → Activate

### Offline-First Architecture

Apps built with Swoff patterns work fully offline:
- Service worker caches all static assets
- App logic runs entirely in the browser
- Data stored in IndexedDB for offline access
- All routes accessible without network

### Framework Support

Currently providing guides for:
- **React + Vite**
- **TanStack Router + Vite**
- **TanStack Start + Vite**

Community contributors can add more frameworks.

## Comparison

| Feature | Swoff | Traditional PWA Libraries |
|---------|-------|---------------------------|
| Dependencies | Zero runtime deps | Often requires npm packages |
| Control | You own the code | Library updates break your app |
| Updates | Consent-based, versioned | Often automatic |
| Offline | Guaranteed by architecture | Depends on library |
| Framework | Agnostic | Often framework-specific |
