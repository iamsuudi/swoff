title: Overview
description: Generate offline-first infrastructure from config.
icon: Zap
---

Swoff generates offline-first infrastructure from a single config file — a service worker, client utilities, and framework adapters for bundler projects. Zero runtime dependencies. Every file is auditable code.

Get started with a single config file:

```bash
npx @swoff/cli init
npx @swoff/cli generate
```
