## What is Swoff?

Swoff is a zero-dependency blueprint for building offline-first, versioned web apps that feel native. It provides patterns, code snippets, and architecture guides for:

- **Guaranteed offline capability** — Versioned service worker with asset caching
- **Zero runtime dependencies** — Code you copy, not npm packages
- **User-consented updates** — No silent SW updates; users control when to update
- **Framework agnostic** — Works with React, Vue, Svelte, or vanilla JS
- **Installable** — PWA-ready with manifest and install prompts

## Philosophy

> We provide code and architecture, not dependencies.

Swoff is not a traditional library. We don't ship an npm package. Instead:

1. **Learn the concepts** — Understand offline-first architecture
2. **Copy our patterns** — Take our service worker, hooks, utilities into your project
3. **Own your code** — Modify, extend, and maintain it yourself

## What Swoff is NOT

- A backend framework — bring your own Go, Node.js, Python, etc.
- An npm package you install
- A replacement for your framework's backend features
- Tied to any specific fullstack framework

:::warning
Swoff focuses on **client-side browser APIs** (offline app shell, data caching, sync) — your backend is your responsibility. We provide patterns for the client, you bring your own Go, Node.js, Python, etc.
:::

## Comparison

| Feature       | Swoff                      | Traditional PWA Libraries                 |
| ------------- | -------------------------- | ----------------------------------------- |
| Dependencies  | Zero runtime deps          | Often requires npm packages               |
| Control       | You own the code           | Library updates break your app            |
| Updates       | Consent-based, versioned   | Often automatic                           |
| Offline       | Guaranteed by architecture | Depends on library                        |
| Framework     | Agnostic                   | Often framework-specific or bundling tool |
| Primary Focus | Client-side web APIs       | Framework features or bundler plugins     |

## Reference Implementation

**Budget Manager** — a 100% offline budget tracking app (special case) built with Swoff patterns:

- 24+ routes working offline
- IndexedDB as full database (no backend needed)
- Versioned SW updates
- PWA installable

*Note: Most Swoff apps use a backend for dynamic data; Budget Manager is a special case where all data is stored locally in IndexedDB.*
