# Introduction

Swoff is a CLI toolbox that generates offline-first infrastructure for your web app. No runtime dependencies — you own the generated code.

## Why Swoff?

- **Config-driven** — toggle features in `swoff.config.json`, the CLI generates everything
- **Zero runtime deps** — the generated files are all you need, no library version conflicts
- **Versioned service worker** — users control when to adopt new versions, no silent breakage
- **Framework-agnostic** — React, Vue, Svelte, or vanilla JS
