## What is Swoff?

Swoff is a zero-dependency blueprint for building offline-first, versioned web apps that feel native. We provide architecture guides and patterns — not npm packages.

## Philosophy

> We provide code and architecture, not dependencies.

Swoff is not a traditional library. You copy our service worker, hooks, and utilities into your project, then modify them to fit your needs. No waiting for library updates, no bundle bloat.

## What Swoff is NOT

- Not an npm package — code you copy, not install
- Not a backend framework — bring your own Go, Node.js, Python
- Not tied to any fullstack framework
- Not focused on server-side features — this is purely client-side

:::warning
Swoff focuses on **client-side browser APIs** (offline app shell, data caching, sync). Your backend is your responsibility.
:::

## Quick Start

:::info
No install needed. Read the guides and copy the code.
:::

1. Understand the [concepts](/docs/concepts/what-is-offline) — offline capability and service workers
2. Learn the [core architecture](/docs/core/offline-architecture) — offline-first principles and data storage
3. Copy [patterns](/docs/patterns/) — SW templates, IndexedDB patterns, build scripts
4. Follow a [framework guide](/docs/guides) — React, TanStack Router, or TanStack Start
5. See the [reference implementation](/docs/reference/budget-manager) — Budget Manager app

## Swoff vs Traditional PWA Libraries

| Feature      | Swoff                      | Traditional PWA Libraries          |
| ------------ | -------------------------- | ---------------------------------- |
| Dependencies | Zero runtime deps          | npm packages                       |
| Control      | You own the code           | Library updates can break your app |
| Updates      | Consent-based, versioned   | Often automatic                    |
| Offline      | Guaranteed by architecture | Depends on library                 |
| Framework    | Agnostic                   | Often framework-specific           |

## Reference Implementation

**Budget Manager** — a 100% offline budget tracking app built with Swoff patterns:

- 24+ routes working offline
- IndexedDB as full database (no backend)
- Versioned SW updates with user consent
- PWA installable

_Note: Most Swoff apps use a backend for dynamic data. Budget Manager is a special case where all data is stored locally._
