# Introduction

Swoff is a **toolbox**, not a framework. Every feature is a file you copy and own.

- **Pick what you need** — skip what you don't
- **Tweak everything** — the code is yours, no library fights you
- **Zero lock-in** — delete the files you don't need

## Quick Start

```bash
npx @swoff/cli init
npx swoff generate
```

This creates:
- `swoff.config.json` — your configuration
- `dist/sw-v{version}.js` — the service worker
- `src/hooks/`, `src/components/` — supporting files

## Two Approaches

### Config-Driven (Recommended)

Edit `swoff.config.json`, run `npx swoff generate`. CLI handles the SW.

```json
{
  "enabled": true,
  "version": "from-package",
  "serviceWorker": {
    "defaultStrategy": "cache-first",
    "strategies": {
      "/api/*": "network-first"
    }
  }
}
```

### Custom Code Mode

Set `"enabled": false` and write your own service worker.
