## What is Swoff?

Swoff is a zero-dependency blueprint for building offline-first, versioned web apps that feel native.

> We provide code and architecture, not dependencies.

Swoff is not a traditional library. You copy our service worker, hooks, and utilities into your project, then modify them to fit your needs. No waiting for library updates, no bundle bloat.

## Modular by Design

Swoff is a **toolbox**, not a framework. Every feature is a file you copy into your project and own.

<Cards>
  <Card title="Pick what you need" icon={<CheckIcon />}>

  </Card>
  <Card title="Tweak everything" icon={<SlidersIcon />}>

## Full Guide

Want to understand everything? Follow these steps in order:

1. Understand the [concepts](/docs/concepts/what-is-offline-and-sw) — offline capability and service workers
2. Learn the [core architecture](/docs/core/offline-architecture) — offline-first principles and data storage
3. Follow the [patterns](/docs/patterns/) sequentially — SW Template → Build Scripts → Client Registration → PWA Installability → IndexedDB Patterns
4. Follow a [framework guide](/docs/guides) — React, TanStack Router, or TanStack Start
5. See the [reference implementation](/docs/reference/budget-manager) — Budget Manager app

## Reference Implementation

**Budget Manager** — a 100% offline budget tracking app built with Swoff patterns:

- 24+ routes working offline
- IndexedDB as full database (no backend)
- Versioned SW updates with user consent
- PWA installable

_Note: Most Swoff apps use a backend for dynamic data. Budget Manager is a special case where all data is stored locally._
