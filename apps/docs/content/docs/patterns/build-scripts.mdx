## Quick Setup

### 1. Create SW Template

Place at `src/sw-template.js`. See [SW Template](/docs/patterns/sw-template) for the code.

### 2. Create Build Script

Create `generate-sw.js` at project root:

```javascript
import { readFileSync, writeFileSync } from "fs";
import { fileURLToPath } from "url";
import { join, dirname } from "path";

const __dirname = dirname(fileURLToPath(import.meta.url));
const pkg = JSON.parse(readFileSync(join(__dirname, "package.json"), "utf8"));
const template = readFileSync(join(__dirname, "src/sw-template.js"), "utf8");

let sw = template.replace("// [[CACHE_NAME]]", `const CACHE_NAME = 'sw-v${pkg.version}'`);
sw = sw.replace("// [[ASSETS_LIST]]", `const ASSETS_TO_CACHE = ['/', '/index.html']`);

writeFileSync(join(__dirname, "dist", `sw-v${pkg.version}.js`), sw);
writeFileSync(join(__dirname, "dist", "version.json"), JSON.stringify({
  version: pkg.version,
  minSupportedVersion: pkg.minSupportedVersion || "0.0.0",
  generatedAt: new Date().toISOString(),
}));
```

**Important:** The `dist` path above is the default. Your framework may use a different output directory (e.g., `.output`, `.next/export`, `build`). See your [framework guide](/docs/guides/) for the correct path.

### 3. Update package.json

```json
{
  "scripts": {
    "build": "vite build && node generate-sw.js"
  }
}
```

### 4. Add TypeScript Declarations

Create `sw.d.ts`. See [Utilities](/docs/patterns/utilities).

### 5. Build & Test

```bash
npm version patch
npm run build
```

Test offline: DevTools → Application → Service Workers → Check "Offline".
