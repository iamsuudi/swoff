# Components

Reusable UI components.

## UpdatePrompt

Shows update dialog when new version available.

```ts title="@components/UpdatePrompt.tsx"
import { UpdatePrompt } from './components/UpdatePrompt'

function App() {
  return (
    <>
      <AppContent />
      <UpdatePrompt />
    </>
  )
}
```

**Behavior:**

- Shows when `updateStatus === 'available'`
- Displays version info
- "Update" button triggers download
- "Later" button dismisses (unless `forceUpdate`)

## SWProgressBar

Progress bar during SW installation.

```ts title="@/components/SWProgressBar"
import { SWProgressBar } from './components/SWProgressBar'

function App() {
  return (
    <>
      <SWProgressBar />
      <AppContent />
    </>
  )
}
```

**Behavior:**

- Fixed at top of screen
- Shows during first SW install
- Auto-hides when complete

---

## InstallButton

Triggers PWA install prompt.

```ts title="@/components/InstallButton"
import { InstallButton } from './components/InstallButton'

function Header() {
  return (
    <header>
      <h1>My App</h1>
      <InstallButton />
    </header>
  )
}
```

**Behavior:**

- Only shows when install prompt available
- Hides after install
- Triggers browser's install prompt
