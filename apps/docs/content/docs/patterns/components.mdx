# Components

Reusable UI components.

## UpdatePrompt

Shows update dialog when new version available.

```ts title="@components/UpdatePrompt.tsx"
import { UpdatePrompt } from './components/UpdatePrompt'

function App() {
  return (
    <>
      <AppContent />
      <UpdatePrompt />
    </>
  )
}
```

**Behavior:**

- Shows when `updateStatus === 'available'`
- Displays version info (e.g., "v0.0.1 → v0.0.2")
- "Update" button triggers download with progress bar
- "Later" button dismisses (unless `forceUpdate` is true)
- If `forceUpdate` is true: full-screen overlay, no dismiss option

## SWProgressBar

Progress bar during SW installation.

```ts title="@/components/SWProgressBar"
import { SWProgressBar } from './components/SWProgressBar'

function App() {
  return (
    <>
      <SWProgressBar />
      <AppContent />
    </>
  )
}
```

**Behavior:**

- Fixed at top of screen
- Shows during first SW install (full-screen progress)
- Auto-hides when complete
- Separate from UpdatePrompt (which shows at bottom as bottom sheet)

---

## InstallButton

Triggers PWA install prompt.

```ts title="@/components/InstallButton"
import { InstallButton } from './components/InstallButton'

function Header() {
  return (
    <header>
      <h1>My App</h1>
      <InstallButton />
    </header>
  )
}
```

**Behavior:**

- Only shows when install prompt available
- Hides after install
- Triggers browser's install prompt
