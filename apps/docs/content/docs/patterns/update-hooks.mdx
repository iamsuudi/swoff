# Hooks

React hooks for Swoff's service worker system.

## usePWAUpdate

Main hook for update flow.

```typescript
const {
  currentVersion, // string | null — currently registered version
  availableVersion, // string | null — version available for update
  updateStatus, // 'idle' | 'available' | 'downloading'
  progress, // number (0-100)
  forceUpdate, // boolean — whether update is mandatory (version < minSupportedVersion)
  dismissUpdate, // () => void — dismiss the update dialog (disabled if forceUpdate)
  acceptUpdate, // () => Promise<void> — download and auto-activate the new version
  checkForUpdates, // () => Promise<void> — manually check version.json
} = usePWAUpdate();
```

**Usage:**

```typescript
function App() {
  const { updateStatus, acceptUpdate } = usePWAUpdate()

  if (updateStatus === 'available') {
    return <button onClick={acceptUpdate}>Update</button>
  }
}
```

## useSWProgress

Track SW download progress.

```typescript
const { progress, status } = useSWProgress();
// status: 'idle' | 'installing' | 'ready' | 'error'
```

**Usage:**

```typescript
function ProgressBar() {
  const { progress, status } = useSWProgress()
  if (status !== 'installing') return null

  return <div style={{ width: `${progress}%` }}>...</div>
}
```

## usePWAVersion

Read current/latest versions.

```typescript
const { currentVersion, latestVersion } = usePWAVersion();
```
