# Hooks

React hooks for Swoff's service worker system.

## usePWAUpdate

Main hook for update flow.

```typescript
const {
  updateStatus,         // 'idle' | 'available' | 'downloading'
  availableVersion,     // string | null
  progress,             // number (0-100)
  forceUpdate,          // boolean
  dismissUpdate,        // () => void
  acceptUpdate,         // () => Promise<void>
} = usePWAUpdate()
```

**Usage:**

```typescript
function App() {
  const { updateStatus, acceptUpdate } = usePWAUpdate()

  if (updateStatus === 'available') {
    return <button onClick={acceptUpdate}>Update</button>
  }
}
```

---

## useSWProgress

Track SW download progress.

```typescript
const { progress, status } = useSWProgress()
// status: 'idle' | 'installing' | 'ready' | 'error'
```

**Usage:**

```typescript
function ProgressBar() {
  const { progress, status } = useSWProgress()
  if (status !== 'installing') return null

  return <div style={{ width: `${progress}%` }}>...</div>
}
```

## usePWAVersion

Read current/latest versions.

```typescript
const { currentVersion, latestVersion } = usePWAVersion()
```
