# PWA Integration

Swoff focuses on service worker and offline functionality, but it works seamlessly with Progressive Web App (PWA) features. This guide shows you how to properly integrate Swoff with PWA capabilities.

## What is PWA?

Progressive Web Apps are web applications that use modern web capabilities to deliver app-like experiences to users. Key PWA features include:

- **Installable** - Can be installed on the user's device
- **Offline-capable** - Works without internet connection
- **Push notifications** - Can send notifications to users
- **App-like experience** - Feels like a native app

## Swoff + PWA Integration

Swoff handles the offline and service worker aspects, while you manage the PWA manifest and installation. This separation of concerns makes it easier to customize your PWA setup.

## Step 4: Service Worker Registration

Register the service worker with proper handling:

```javascript
// src/sw-registration.js
export const registerServiceWorker = () => {
  if ("serviceWorker" in navigator) {
    const version = import.meta.env.VITE_APP_VERSION || "1.0.0";

    navigator.serviceWorker
      .register(`/sw-v${version}.js`)
      .then((registration) => {
        console.log("Service Worker registered:", registration);

        // Handle updates
        registration.addEventListener("updatefound", () => {
          const installingWorker = registration.installing;
          installingWorker?.addEventListener("statechange", () => {
            if (
              installingWorker.state === "installed" &&
              navigator.serviceWorker.controller
            ) {
              console.log("New version available");
              showUpdateNotification();
            }
          });
        });

        // Handle controller change
        navigator.serviceWorker.addEventListener("controllerchange", () => {
          console.log("New service worker activated");
          window.location.reload();
        });
      })
      .catch((error) => {
        console.error("Service Worker registration failed:", error);
      });
  }
};

// Show update notification
const showUpdateNotification = () => {
  if ("Notification" in window && Notification.permission === "granted") {
    new Notification("Update Available", {
      body: "A new version of the app is available. Click to update.",
      icon: "/icons/icon-192.png",
      tag: "update-available",
    });
  }
};

// Request notification permission
export const requestNotificationPermission = async () => {
  if ("Notification" in window && Notification.permission === "default") {
    const permission = await Notification.requestPermission();
    return permission === "granted";
  }
  return Notification.permission === "granted";
};

// Initialize
if (typeof window !== "undefined") {
  registerServiceWorker();
  requestNotificationPermission();
}
```

## Step 5: PWA Installation Handler

Create a component to handle PWA installation:

```javascript
// src/components/PWAInstallButton.js
import { useState, useEffect } from "react";

export const PWAInstallButton = () => {
  const [isInstallable, setIsInstallable] = useState(false);
  const [deferredPrompt, setDeferredPrompt] = useState(null);

  useEffect(() => {
    const handleBeforeInstallPrompt = (e) => {
      e.preventDefault();
      setDeferredPrompt(e);
      setIsInstallable(true);
    };

    window.addEventListener("beforeinstallprompt", handleBeforeInstallPrompt);

    return () => {
      window.removeEventListener(
        "beforeinstallprompt",
        handleBeforeInstallPrompt,
      );
    };
  }, []);

  const handleInstall = async () => {
    if (!deferredPrompt) return;

    try {
      await deferredPrompt.prompt();
      const { outcome } = await deferredPrompt.userChoice;
      console.log("User choice:", outcome);

      setDeferredPrompt(null);
      setIsInstallable(false);
    } catch (error) {
      console.error("Installation failed:", error);
    }
  };

  if (!isInstallable) return null;

  return (
    <button
      onClick={handleInstall}
      className="fixed bottom-4 right-4 bg-blue-500 text-white px-4 py-2 rounded-lg shadow-lg hover:bg-blue-600 z-50"
    >
      Install App
    </button>
  );
};
```

## Step 6: Offline Support Components

Create components that handle offline scenarios:

```javascript
// src/components/OfflineIndicator.js
import { useState, useEffect } from "react";

export const OfflineIndicator = () => {
  const [isOnline, setIsOnline] = useState(navigator.onLine);

  useEffect(() => {
    const handleOnline = () => setIsOnline(true);
    const handleOffline = () => setIsOnline(false);

    window.addEventListener("online", handleOnline);
    window.addEventListener("offline", handleOffline);

    return () => {
      window.removeEventListener("online", handleOnline);
      window.removeEventListener("offline", handleOffline);
    };
  }, []);

  if (isOnline) return null;

  return (
    <div className="fixed top-4 right-4 bg-red-500 text-white px-4 py-2 rounded-lg shadow-lg z-50">
```

## Step 7: Push Notifications

Set up push notifications for your PWA:

```javascript
// src/utils/pushNotifications.js
export const setupPushNotifications = async () => {
  if (!("serviceWorker" in navigator)) {
    console.log("Service Workers not supported");
    return false;
  }

  try {
    // Request notification permission
    const permission = await Notification.requestPermission();
    if (permission !== "granted") {
      console.log("Notification permission denied");
      return false;
    }

    // Register service worker if not already registered
    if (!navigator.serviceWorker.controller) {
      await navigator.serviceWorker.ready;
    }

    // Subscribe to push notifications
    const registration = await navigator.serviceWorker.ready;
    const subscription = await registration.pushManager.subscribe({
      userVisibleOnly: true,
      applicationServerKey: urlBase64ToUint8Array("YOUR_VAPID_PUBLIC_KEY"),
    });

    console.log("Push notification subscription:", subscription);
    return subscription;
  } catch (error) {
    console.error("Error setting up push notifications:", error);
    return false;
  }
};

// Helper function to convert VAPID public key
function urlBase64ToUint8Array(base64String) {
  const padding = "=".repeat((4 - (base64String.length % 4)) % 4);
  const base64 = (base64String + padding)
    .replace(/\-/g, "+")
    .replace(/_/g, "/");

  const rawData = window.atob(base64);
  const outputArray = new Uint8Array(rawData.length);

  for (let i = 0; i < rawData.length; ++i) {
    outputArray[i] = rawData.charCodeAt(i);
  }

  return outputArray;
}
```

## PWA Manifest Best Practices

### Icons

- **Multiple sizes**: Include 192x192, 512x512, and other common sizes
- **Purpose**: Include both `any` and `maskable` icons
- **Format**: Use PNG format with transparency
- **Square aspect ratio**: All icons should be square

### Manifest Fields

- **name**: Full app name (30 characters max)
- **short_name**: Shorter name for home screen (12 characters max)
- **start_url**: Should be `/` for root level
- **display**: Use `standalone` for app-like experience
- **theme_color**: Should match your app's primary color
- **background_color**: Should match your app's background

### Screenshots

Include screenshots for different devices:

- **Desktop**: 1280x720px or 1920x1080px
- **Mobile**: 750x1334px or similar mobile aspect ratio
- **Multiple orientations**: Include both portrait and landscape if applicable

### Shortcuts

Add shortcuts for common actions:

- **Name**: Should be clear and concise
- **URL**: Should be accessible without authentication
- **Icons**: Use appropriate icons for each shortcut

```javascript
// Send push notification
const sendPushNotification = async (subscription, message) => {
  try {
    const response = await fetch("/api/send-notification", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        subscription,
        message,
      }),
    });

    if (!response.ok) {
      throw new Error("Failed to send notification");
    }

    console.log("Notification sent successfully");
  } catch (error) {
    console.error("Error sending notification:", error);
  }
};
```

## Troubleshooting

### Common PWA Issues

1. **Manifest not loading**
   - Check file path and permissions
   - Verify JSON syntax
   - Check browser console for errors

2. **Service worker not registering**
   - Ensure HTTPS in production
   - Check file path and accessibility
   - Verify service worker scope

3. **Install prompt not showing**
   - Check manifest.json fields
   - Verify app meets installability criteria
   - Test in different browsers

4. **Offline features not working**
   - Check service worker registration
   - Verify cache strategies
   - Test with DevTools offline mode

### Debugging Tools

- **Chrome DevTools**: Service Workers tab and Lighthouse audit
- **WebPageTest**: Test performance across different conditions
- **PWA Validator**: Online validation tool for manifest.json
- **BrowserStack**: Test on different browsers and devices
