# Swoff Demo App — Tanstack Start + Nitro

An offline-first PWA example built with [Swoff](https://github.com/iamsuudi/swoff), React 19, Tanstack Start, Nitro, Vite and Tailwind CSS v4. Demonstrates service worker caching, tag-based cache invalidation, offline mutation queuing, background sync, three backend auth patterns, a GraphQL wrapper with cache-key hashing, and Web Push notifications.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start the API server (choose one auth pattern)
npm run server:bearer

# 3. In another terminal, start the dev server
npm run pwa:local
```
